# NOISE / 情報のノイズ

零依赖的全屏缩放信息灯海。远看是星河，近看是密集的日本品牌风格霓虹灯箱。无透视街道、无照片显示。

## 运行

在项目目录运行 `npm run dev`，打开 http://localhost:4173 。也可用任意静态服务器托管 dist。

## 内容与交互

19,000 个灯点与 1,850 个灯箱。滚轮、双指或滑杆缩放，拖动探索，↺ 返回远眺。键盘 + / − 缩放、方向键移动、Home 复位。

灯箱分别绘制：堂吉诃德黑黄主牌与红黄标题、カラオケ館蓝白竖牌与横牌、TOWER RECORDS 红黄字、TSUTAYA、109、一蘭等品牌风格。使用系统日文字体近似绘制，不宣称为官方字标。包括灯箱金属边、玻璃高光、发光描边与光晕。

SOUND 默认尝试自动开启之前版本的程序合成都市声景：交通低鸣与电车提示音，随距离改变音量与低通。浏览器阻止自动播放时，在第一次点击或键盘操作后开启；主动关闭后不自动重开。MOTION 关闭环境动态与缩放缓动，自动遵循系统减少动态设置。

ABOUT 为独立日中双语构思页：离开东京时的怀念，与身处都市中心时的感官过载。

## 文件

- dist/index.html：极简交互界面
- dist/app.js：Canvas 灯海、灯箱绘制、缩放与采样声音处理
- dist/style.css：响应式样式
- dist/about.html：作品构思
- dist/assets/shibuya-field-recording.mp3：作者提供的声音采样

Canvas 视野裁剪、缓存灯箱纹理、30 FPS 上限、移动端灯点减半和 1.5 倍像素密度上限。品牌名称用于艺术性模拟，无实时广告或品牌合作。新增荧光蓝与荧光粉的空心霓虹字、深色透明底牌与柔和光晕，降低排列密度。

## 独立灯箱与隐藏心声
现为 1,200 块独立灯箱记录。品牌不再大量复制，其余为不同名称的虚构商店，以及 20 句心声在 6 种都市时刻下构成的 120 块匿名灯牌。纹理按可见范围生成，并限制缓存数量。

点击灯箱打开日中详情、播放场景声音；顶部 UNHEARD VOICES 与 CITY SOUNDS 也可用键盘进入。详情可重播、选择代表招牌和浏览下一条，Esc 关闭。入店/促销等短旋律为原创合成，非真实品牌歌曲。匿名心声为创作文本，通过浏览器日语语音合成朗读，非真实受访者录音；设备缺少日语语音时仍可阅读文字。关闭详情、静音或隐藏页面会停止相应声音。

## 暖色远景与流畅度优化
远景为橙红、橙黄金色灯海，逐渐过渡到近处多彩霓虹。纹理改为低分辨率驻留缓存，并每批至多生成 3 张，避免重复重建；光晕使用预绘制图像，缩放中提高绘制频率，音频参数只在状态变化时更新。详情已移除声音下拉框和顶部声音菜单，点击招牌直接触发声音。FamilyMart 使用熟悉入店旋律的音程与节奏进行电子钟音重现，非原始门店录音；LAWSON、7-Eleven 为一般入店双音提示的合成意象，不宣称还原所有门店。

入店旋律参考：https://zenn.dev/tanny/articles/0acb5472ecdb84 。

## 日语与简短详情
首页、灯箱、按钮与声音状态均统一为日语。详情仅显示标题与一句短文，移除重复的日中段落。about.html 保持原中日双语内容不变。远景灯点混合白、冷白、暖白和少量橙黄，降低橙红底雾。
